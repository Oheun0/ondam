# 🧥 온담 (OnDam)

> 접근성 중심 패션 플랫폼 (JSP/Servlet 기반 팀 프로젝트)

---

## 📌 프로젝트 소개

온담(OnDam)은 **중장년층 및 노년층 사용자를 위한 접근성 중심 패션 플랫폼**으로,  
복잡한 UI와 어려운 패션 용어로 인해 의류 선택에 어려움을 겪는 문제를 해결하기 위해 기획되었습니다.
사용자가 쉽게 탐색하고, **“내 사람”과의 관계를 통해 구매를 이어가는 새로운 쇼핑 경험**을 제공합니다.

---

## 🎯 핵심 가치

- 👀 **쉬운 탐색**  
  → 쇼츠 기반 이미지 탐색 + 직관적인 UI

- 🛒 **쉬운 구매**  
  → 최소 입력 기반 주문 구조

- 🤝 **관계 기반 소비**  
  → 내 사람 그룹을 통한 조르기 / 선물 / 함께 지갑

---

## 🧩 주요 기능

### 🏠 홈
- 추천 배너
- AI 추천 요약
- 최근 본 상품
- 내 사람 활동

### 🎬 쇼츠 탐색
- 영상 기반 상품 탐색
- 찜 / 장바구니 / 조르기 / 선물하기

### 🤖 AI 추천
- 상황 기반 추천
- 사용자 취향 기반 추천
- 행동 기반 추천

### 👨‍👩‍👧 내 사람
- 그룹 기반 관계 시스템
- 조르기 요청
- 선물 내역
- 함께 지갑
- 활동 공유

### 🛍️ 상품 & 주문
- 상품 상세
- 옵션 선택
- 장바구니
- 주문 / 결제 / 배송 상태

### 🔔 알림
- 조르기 / 선물 / 주문 상태 알림
- 추천 / 혜택 알림
